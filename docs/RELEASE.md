# Release

WOIA Core releases are produced only by authorized Turpial AI Academy WOIA maintainers/developers through the woia-ecosystem Factory.

Before a release candidate:

1. regenerate CHECKSUMS.sha256;
2. run the repository's proportional local gates;
3. commit an exact clean candidate;
4. certify it through woia-ecosystem plugin:certify;
5. prepare immutable release evidence;
6. run publication preflight;
7. obtain explicit maintainer publication authorization;
8. publish the exact tag/asset;
9. admit the verified release into the WOIA global registry;
10. regenerate affected department marketplaces.

Published tags/releases are immutable. Fixes create a new SemVer version.
